# Чек-лист выпуска в App Store

## 1. Настройка проекта

- [ ] В таргете `Kopilka` → Signing & Capabilities выбрать свою команду (`DEVELOPMENT_TEAM`).
- [ ] Заменить `PRODUCT_BUNDLE_IDENTIFIER` (`com.qquebak.kopilka`) на свой идентификатор.
- [ ] Проверить `MARKETING_VERSION` (1.0) и `CURRENT_PROJECT_VERSION` (1).
- [ ] Собрать на устройстве, а не только в симуляторе.

## 2. Проверка перед сдачей

- [ ] Первый запуск: онбординг, выбор валюты, создание цели.
- [ ] Пополнение, снятие, удаление операции, закрытие цели (конфетти).
- [ ] Тёмная и светлая темы, крупный системный шрифт (Accessibility → Larger Text).
- [ ] «Уменьшение движения»: анимации фона и конфетти отключаются.
- [ ] Перезапуск приложения — данные на месте.
- [ ] «Удалить все данные» очищает список и статистику.
- [ ] Напоминание: запрос разрешения, отказ обрабатывается без залипания переключателя.
- [ ] VoiceOver проходит по карточкам целей, кольцу прогресса и графику.

## 3. App Store Connect

- [ ] Создать приложение, категория «Финансы», рейтинг 4+.
- [ ] Заполнить локализации из `metadata-ru.md` и `metadata-en.md`.
- [ ] Анкета App Privacy — по `privacy.md` (данные не собираются).
- [ ] Указать URL политики конфиденциальности (обязателен для всех приложений).
- [ ] Заметка для ревью: «Приложение полностью офлайн, аккаунт не требуется,
      покупок нет. Демо-данные можно загрузить: Настройки → Загрузить демо-данные».
- [ ] Загрузить сборку через Xcode → Product → Archive → Distribute App.

## 4. Скриншоты

Обязательные размеры: 6.9" (1320 × 2868) и 6.5" (1242 × 2688); iPad — по желанию,
если сдаёте универсальную сборку.

План из шести кадров (снимать с загруженными демо-данными):

1. **Главный экран** — общий баланс и список целей. Подпись: «Все цели на одном экране».
2. **Экран цели** — кольцо прогресса и вехи. Подпись: «Видно, сколько осталось».
3. **Пополнение** — клавиатура сумм и быстрые кнопки. Подпись: «Пополнение за пару секунд».
4. **Статистика** — плитки и график по месяцам. Подпись: «Динамика по месяцам».
5. **Новая цель** — выбор иконки и цвета. Подпись: «Своя иконка и цвет для каждой цели».
6. **Тёмная тема** — главный экран ночью. Подпись: «Светлая и тёмная темы».

## 5. После релиза

- [ ] Отслеживать отзывы и организовать ответы через App Store Connect.
- [ ] Следующие кандидаты в бэклог: виджеты на главном экране, Apple Watch,
      экспорт истории в CSV, iCloud-синхронизация.
